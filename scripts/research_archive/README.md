2026-09-25 `tmp/` 정리 과정에서 향후 결과 재현에 필요한 스크립트를 원형 그대로 보관했다. 서비스 실행에는 필요하지 않다.

| 폴더 | 보관한 역할 |
|---|---|
| `policy_research_20260925/` | 공식 출처 수집, TourAPI 상세 조회, 데이터 목록 작성, 정책 인계본 생성, 적재·SQL 검증 |
| `region_review_20260924/` | 원본 해시 확인·분석 재현, 분석 주석 보고서 생성 |
| `wbs_20260924_0930/` | WBS 일정·역할·서식 생성 |

이 코드는 **당시 작업 경로와 날짜를 보존한 기록**이다. 이동된 위치에서 곧바로 실행하는 범용 도구가 아니다. 일부 스크립트는 기존 결과를 덮어쓰거나 API를 다시 호출하므로, 현재 결과를 백업하고 출력 경로를 검토한 뒤 사용한다. WBS 스크립트는 실행 당시의 사용자 절대경로도 포함한다.

당시의 재현 입력과 공모요강 발췌 이미지는 로컬 `data/research_archive/tmp_cleanup_20260925/inputs/`에 있다. 이 폴더는 원본 데이터와 같은 Git 제외 정책을 따른다. `data/research_archive/tmp_cleanup_20260925/cleanup_plan.json`과 `cleanup_result.json`에서 원래 위치·보관 위치·SHA-256·삭제 이유를 확인할 수 있다.

재현하려면 해당 작업의 스크립트를 원래 `tmp/<작업명>/` 위치에 복사하고, 보관 입력을 `inputs/` 아래 상대경로 그대로 복원한다. 최종 결과와 중복되어 삭제한 입력은 정리 기록의 `duplicate_of` 파일에서 원래 위치로 복사할 수 있다. 지역 분석의 재실행 결과(`replayed_*`)는 `inspect_evidence.py`로 다시 만들 수 있다. 캐시·시험 DB·렌더링 미리보기는 다시 생성한다.

정책 인계본의 공개 근거 원문은 `outputs/policy_review_20260925/evidence/`, 분석 원본은 기존 `data/`·`runs/`, 최종 WBS는 `outputs/wbs_20260924_0930/`에 유지했다. `node_modules` 연결 대상인 Codex 공용 라이브러리는 삭제하지 않았다. WBS를 재생성할 때는 해당 실행 환경의 `@oai/artifact-tool` 의존성을 다시 연결해야 한다.
