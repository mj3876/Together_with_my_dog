# WBS 2.3 실제 장소·동반 규정 검토본

확인일: 2026-09-25 · 범위: 대전 · 조사 방법: 공식 홈페이지·운영자 예약 페이지·TourAPI 조회

공식 자료 조사와 검토본·인계 파일 작성을 마쳤다. **추천 활성화에 필요한 마릿수·체중·공간·회차 조건은 추가 확인이 필요하다.** 이번 조사로 활성화할 장소는 0건이다. 전화 확인이나 담당자 회신을 받은 것으로 처리하지 않았으며, A에게 외부 메시지를 발송하지 않았다. WBS의 ‘실제 추천에 사용할 데이터 확보’까지 완료한 것으로 표시해서는 안 된다.

## 1. 확보 자료와 인계 파일

| 파일 | 내용 | 사용 방법 |
|---|---|---|
| `restaurant_registrations.json` | 대전시 음식점 등록 69건, 원본 행·병합 셀·관할기관 공란 보존 | `food_registrations` 적재 원천 |
| `restaurant_candidates.json` | 상호·주소 기준 음식점 후보 68곳 | 좌표와 세부 규정 보완 전 대기 자료; 현 `Place` 스키마로 직접 적재 불가 |
| `policy_review.json` | 숙박 1상품, 공원 4공간, 교육 4프로그램의 확인 내용과 미확인 항목 | 규정 검토 및 `offerings`/`pet_policy_versions` 설계 입력 |
| `places_import_inactive.json` | 현재 서비스 스키마에 맞춘 비활성 레코드 9건 | 별도 DB 적재 검증 완료 후 인계; 실제 추천에 사용하지 않음 |
| `sources.json`, `evidence/` | 공식 원본, 조회 시각, 출처 URL, SHA-256 | 근거 추적; API 키 미포함 |
| `validation.json` | 건수·스키마·시험 DB 적재·SQL 제약 검증 결과 | 작업 검증 기록 |

`policy.verified=false`는 확인된 사실도 없다는 뜻이 아니라 **자동 추천에 필요한 규정 전체의 검증이 끝나지 않았음**을 뜻한다. 확인한 사실은 검토본 및 출처에 따로 남겼다. 음식점의 좌표 공란에 공원 좌표나 임의 좌표를 채우지 않는다.

## 2. 음식점: 등록 사실과 이용조건을 구분

[대전시 2026-09-07 등록 현황](https://www.daejeon.go.kr/drh/board/boardNormalView.do?boardId=normal_0096&menuSeq=1631&ntatcSeq=1521961064)의 첨부 XLSX를 직접 확인했다. 등록 69건은 일반음식점 50건, 휴게음식점 17건, 제과점영업 2건이다. 구별 등록 수는 동구 17, 중구 2, 서구 34, 유성구 14, 대덕구 2건이다.

- `대전!D67:D68`, `E67:E68`은 병합 셀이다. 연번 64·65는 같은 **콩월 / 유성구 덕명서로2번길 19**이며 일반음식점·제과점영업으로 각각 등록되어 있다. 장소를 두 개 만들지 않는다. 68곳은 상호·주소 일치에 따른 잠정 중복 정리 수치다.
- `B42`, `B48`의 관할기관은 원본 공란이다. 주소에서 서구를 보완하되 원본과 보완 근거를 별도 필드에 보존했다.
- 등록 명부는 체중·마릿수·공간·영업시간·식사 메뉴·좌표를 제공하지 않는다. 등록 사실만으로 `weight_unlimited`, `dogs_unlimited`, `serves_meals`, `active`를 참으로 만들 수 없다.
- 일반음식점에는 카페도 포함되어 있으므로 업종 코드로 식사 제공 여부를 단정하지 않는다.

후속 확인 우선 후보는 대전버거, 그로브소제, 후루룩 대전 등이다. 우선순위는 메뉴·운영 확인을 시작할 대상을 정한 작업 판단이며, 세부 규정 검증이나 추천 승인 의미가 아니다. 68곳 전체의 미확인 필드는 후보 JSON에 기록했다.

## 3. 숙박: 빨간대문 독채

주소는 대전광역시 동구 계족로 194-1, TourAPI 콘텐츠 ID는 `3533154`이다. [운영자 Airbnb 상품](https://www.airbnb.co.kr/rooms/1256582248927052245)에서 반려동물 동반 허용과 반려견 용품 제공을 확인했다. TourAPI `detailPetTour2`도 반려견·전구역 동반을 안내하며, `detailIntro2`는 15시 입실·11시 퇴실을 안내한다. 기본정보의 좌표는 경도 127.4418384792, 위도 36.3308438742이다.

상품 단위는 **독채 전체**로 잡는다. TourAPI의 한실 1실 표기와 예약 페이지의 침실 2개 표기는 ‘독채 상품 수’와 ‘내부 침실 수’일 수 있으므로 서로 같은 객실 수 열로 덮어쓰지 않는다. 네이버 예약 링크는 확인했지만 페이지 본문은 읽지 못했다.

미확인: 반려견 최대 마릿수, 체중 상한과 포함/미만 경계, 견종 제한, 추가요금, 방문일 예약 가능 여부. `자유이용`이나 `전구역`은 체중·마릿수 무제한의 근거가 아니다. 기존 `tour_3533154` ID를 유지하며 이 인계본과 기존 `data/curated/tourapi_review.json`을 한 번에 입력하면 중복 ID가 되므로 둘 중 새 검토본만 사용한다.

## 4. 공원: 하나의 장소에 네 개 공간

대전반려동물공원은 유성구 금고길 7, TourAPI 콘텐츠 ID `2930677`이다. [시설 안내](https://www.daejeon.go.kr/ani/AniContentsHtmlView.do?menuSeq=7368)에 따라 공간을 나눴다.

| 공간 | 확인한 제한 | 추천 처리 |
|---|---|---|
| 중·소형견 야외놀이터 | 체고 40cm 미만 | 체중으로 환산 금지 |
| 대형견 야외놀이터 | 체고 40cm 이상 | 40cm는 이쪽 경계에 포함 |
| 실내놀이터 | 중·소형견 전용, 실내 기저귀/매너밴드 | 야외와 별도 규정 |
| 어질리티 파크 | 대형견 전용 | 교육 프로그램과 구별 |

[이용 안내](https://www.daejeon.go.kr/ani/AniContentsHtmlView.do?menuSeq=7367)는 동물등록·광견병 예방접종, 2개월 이상, 제한 견종 및 공격성 개체 제외, 놀이터 밖 2m 이내 목줄 등을 요구한다. 현 서비스의 체중·마릿수 입력만으로 체고·견종·등록 여부를 확인할 수 없으므로 비활성으로 보관한다.

문화센터는 10~18시, 입장 마감 17:30이다. 야외는 4~9월 10~21시(입장 20시), 10~3월 10~19시(입장 18시)로 구분된다. 월요일과 공휴일 대체 휴무, 명절 예외를 단일 영업시간으로 축약하지 않는다. **마지막 입장시간과 폐장시간은 별도 값**이다.

[2026-09-11 추석 휴관 공지](https://www.daejeon.go.kr/ani/AniNoticeView.do?ntatcSeq=1522349952&menuSeq=3107)의 이미지에서 9월 24~26일 휴관을 확인했다. 원문 JPG를 보관했다. [어질리티장 공사 공지](https://www.daejeon.go.kr/ani/AniNoticeView.do?ntatcSeq=1518200451&menuSeq=3107)는 7월 27~31일의 제한이며, 이 공지만으로 현재도 공사 중이라고 판단하지 않는다.

## 5. 프로그램: 정규 안내와 실제 회차를 분리

[2026 교육 프로그램 안내](https://www.daejeon.go.kr/ani/AniContentsHtmlView.do?menuSeq=7369)는 하반기 9~11월 교육, OK예약 접수, 대전 시민 우선을 안내한다.

| 프로그램 | 확인 내용 | 미확인 |
|---|---|---|
| 행동교정교육 | 보호자와 반려견 참여, 문화센터 행동교육실, 무료 | 현재 회차·소요시간·체중·마릿수·외지인 자격 |
| 스포츠 체험교육 | 반려견과 어질리티 체험, 실내놀이터 또는 야외훈련장 | 공간별 참가조건·현재 모집·회차 |
| 수제간식 만들기 | 교육·세미나실, 교육비 무료·재료비 별도 | 반려견 실내 동반/참여 허용 여부 |
| 반려견 통합사회화 | 행동교육실, 선착순 예약 | 실제 참여 방식과 현재 모집 조건 |

공원에 들어갈 수 있다는 사실을 모든 교실·회차의 동반 허용으로 확대하지 않는다. 행동교정·스포츠 교육은 반려견 참여 설명을 확인했지만 회차별 조건은 미검증이다. 간식 만들기·통합사회화의 동반 범위는 검토 JSON에서 **NULL**이다. 현재 앱은 NULL을 지원하지 않아 호환 적재본에서만 `pet_allowed=false`, `verified=false`, `active=false`로 보류하며, 이는 금지 확인값이 아니다. 정규화 DB로 옮길 때 검토 JSON의 NULL을 따른다. 교육 안내에 존재한다는 이유만으로 날짜에 상관없이 제공 가능한 상시 체험으로 활성화하지 않는다. 지난 상반기 일정과 여름 물놀이 회차는 현재 예약 가능 근거에서 제외한다.

## 6. A에게 전달할 적재 기준

1. 이 폴더와 `docs/data_inventory_and_db_design.md`, `docs/database_schema.sql`을 인계한다.
2. 현 앱 호환 확인은 별도 DB에서 다음과 같이 한다. 실제 DB 반영 전에 기존 레코드와 ID 중복을 확인한다.

```powershell
.\.venv\Scripts\python.exe -m scripts.build_service_db outputs/policy_review_20260925/places_import_inactive.json --database tmp/policy_research_20260925/handoff_check.db
```

3. 68개 음식점은 정확한 좌표와 세부 규정을 보완한 뒤 서비스용 데이터로 전환한다. 업체별 연락 내용은 현재 모두 미실시다.
4. 운영자 확인 질문: 허용 객실·공간·회차 이름, 일행/보호자당 마릿수, 체중 경계, 체고/견종 조건, 추가요금, 준비물, 영업·예약시간. 답변 출처·확인일·담당자 역할을 기록한다.
5. `active=true` 전환은 규정 검증 및 앱이 모든 필수 조건을 판별할 수 있는지 검토한 뒤 진행한다.

검토본 작성 및 로컬 인계 준비 완료와, 모든 장소의 운영 승인 완료는 서로 다른 상태다. 원본 WBS 파일의 상태 셀은 수정하지 않았다.
